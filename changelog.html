Changelog
What's new in Vorsa

Every release, fix, and improvement — documented as it ships. Follow along as Vorsa evolves from MVP to full platform.

July 21, 2026
v0.5 — MVP
Latest
B2B / B2C fork + smart channel selector
The biggest product change since launch. Vorsa now has two fully distinct paths — one built for business buyers, one for individual consumers. Every intake question, campaign type, channel option, agent prompt, and QA rule is now mode-specific.
N
Mode selector — B2B or B2C fork at onboarding entry. Hard fork, not a toggle. Mode is locked to workspace.
N
Divergent Act 2 intake — B2B captures buyer title, company size, buying committee, deal cycle, business pain. B2C captures customer descriptor, life stage, shopping channels, purchase trigger, emotional driver, and aspiration.
N
Smart channel selector — Claude API recommends the optimal channel mix based on campaign type, key message, and goal. Returns role (Primary / Supporting / Optional) and one-line rationale per channel. User confirms or adjusts before proceeding.
N
7 B2C channels — email sequence, Instagram captions, TikTok/Reels script, SMS copy, paid ad copy, product page copy, influencer brief.
N
7 B2B channels — email nurture, cold outreach, LinkedIn posts, landing page, sales battlecard, event follow-up sequence.
N
Forked system prompts — buildSys() now branches into B2B (expert-to-expert, ROI-first, no warm-up) or B2C (benefit-first, emotion-second, FTC-aware, Grade 7-8 readability) agent persona.
N
Mode-specific QA rules — B2B hard stops include cold outreach opening with "I", passive voice clusters, unattributed stats. B2C hard stops include fake scarcity, unsubstantiated superlatives, FTC-triggering influencer language.
N
9 B2C campaign types — product launch, seasonal promo, cart abandonment, loyalty/retention, influencer brief, UGC campaign, brand awareness, win-back, new collection.
I
Mode badge in sidebar and campaign header — always visible, no ambiguity about which agent you're working with.
July 20, 2026
v0.4
Onboarding v2 + full command center
Complete rebuild of the intake flow and campaign pipeline. The app now mirrors the Finzly campaign engine architecture, adapted for vertical-agnostic use.
N
3-act progressive onboarding — Foundation, Audience, Voice + Guardrails. 10 total fields. Each feeds directly into the repository schema.
N
Repository health scores — live scoring across 6 dimensions shown on review screen.
N
5-stage campaign pipeline — Signal → Strategy → Assets → QA → Production Ready.
N
QA agent — 3-round automated review: Brand/Voice, Claims/Accuracy, Conversion Effectiveness. Hard stop / Major / Minor severity classification.
N
Asset tab parsing — output parsed by channel markers into individual tabs per asset type.
N
Campaign library — save completed campaigns, browse by type, view assets by channel tab.
I
Prompt architecture — buildSys(), buildStrategyPrompt(), buildAssetPrompt(), buildQAPrompt() wired to Claude Sonnet 4.6.
